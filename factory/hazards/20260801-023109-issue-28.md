# Hazards — DreamConnect (fragment: issue #28, dangling systemd enablement symlink)

Read by the `breaker` before every red team; appended by `/submit`. Not a bug list — the issue tracker
holds work. This holds *where trouble has been found before, and what has already been ruled out*.

A rule-out is evidence only while the code it names is unchanged, which is why every row carries a path
and the commit it was established at. Expiry is checked with **both** `git log <commit>..HEAD -- <path>`
and `git diff HEAD -- <path>` — a red team works on an uncommitted tree, so `git log` alone cannot see
the change it is there to attack.

## Held — found once, now guarded by a test

| hazard | path | test that holds it | commit |
|---|---|---|---|

Removing from the issue's suggested path would have silently fixed nothing — no box has ever had a `default.target.wants/dreamconnect-daemon.service` symlink | `install.sh :: uninstall()`, `systemd/dreamconnect-daemon.service` | `test_install_sh_removes_the_dangling_enablement_symlink_before_the_unit_file` (derives the expected path dynamically from the unit file's own `WantedBy=` line, rather than hardcoding either path) | 6d92209 |

## Ruled out — probed with evidence, no defect found

| hypothesis | path | evidence | established at |
|---|---|---|---|
| A mutant removing from the WRONG directory (a typo like a trailing dot, or an underscore instead of a hyphen) could still pass the new test | `install.sh :: uninstall()`, `test_install.sh` | Hand-simulated both mutations against the regex the test actually builds — both correctly produce NO MATCH, since the test derives the expected path dynamically from the unit file rather than a hardcoded literal | 6d92209 |

| The new line is skipped correctly (along with its sibling) when `valid_home_dir "$target_home"` is false (unusable home) | `install.sh :: uninstall()` | Confirmed: the new line sits inside the same `if valid_home_dir ... then ... else ...` block as the pre-existing unit-file removal; the `else` branch skips both together | 6d92209 |
