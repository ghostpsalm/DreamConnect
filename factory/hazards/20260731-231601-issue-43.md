## Ruled out — probed with evidence, no defect found
| hypothesis | path | evidence | established at |
|---|---|---|---|
| Exit-code swallowing: `set -euo pipefail` might not cover the `echo ... \| sha256sum -c -` pipeline, or something between the top of the script and this line unsets `pipefail`. | `agent/build.sh` | Pipeline is top-level, not inside an `if`/`&&`/`\|\|`/a function that would suppress it beyond the deliberate `if !` guard; nothing unsets `pipefail`; mutants confirmed abort, not warn. `build.sh` reads zero environment variables, so the check cannot be disabled from outside. | 08d7690 |
| The pinned `BB_SHA256` constant is wrong. | `agent/build.sh` | Cross-checked three times across two breaker laps and a seraph pass: `sha256sum` of the locally cached jar, a live `curl` of Maven Central's own `.sha256` sidecar, and re-fetching the jar itself — all agree on `e32f454c2c1f4aca982f9ec764ed892d9a6eee7e8a77f435cbdd180f6ffdb821`. | 08d7690 |
| `rm -f "$BB_JAR"` could escape `agent/lib/` via a bad `HERE` computation or symlink following. | `agent/build.sh` | `BB_JAR` is built from fixed path components (`$HERE/lib/byte-buddy-$BYTEBUDDY_VERSION.jar`) with no attacker-controlled input; `rm -f` unlinks a symlink itself, it never follows one to a target. | 08d7690 |
| `rm -f` firing on the success path by mistake, or a quoting/`pipefail`/`if !` subtlety flipping the branch taken. | `agent/build.sh` | Real ByteBuddy jar (hash matches pin) run end to end: full suite including the happy-path case green, agent jar assembled, `rm -f` branch never entered. | 08d7690 |
| A failing `rm -f` (e.g. permission-denied on `lib/`) could still print "removed the rejected jar" — the message would be a lie. | `agent/build.sh` | `set -e` is active inside the `then` branch, so a failing `rm -f` aborts before the echo runs. Demonstrated with `chmod a-w lib`: `rm: Permission denied`, exit 1, no "removed" line, jar left intact. | 08d7690 |
| `sha256sum -c` misparsing a `$BB_JAR` path containing a backslash. | `agent/build.sh` | coreutils 9.10 only unescapes a checksum line that itself starts with a leading `\`; the constructed line here never does. No false rejection observed. | 08d7690 |

## Unprobed — no oracle available
| hypothesis | path | what would settle it |
|---|---|---|
| Verify-then-reread TOCTOU: the hash is checked once, but `javac -cp "$BB_JAR:..."` and `unzip -oq "$BB_JAR" 'net/*'` reread the same path afterward. Demonstrated exploitable with a `javac` wrapper that swaps the file post-verification (filed as #48); whether a *realistic* attacker (write access to `agent/lib/` only, no PATH control) can win the timing window without such a wrapper is unprobed. | `agent/build.sh` | A fixed race harness that swaps the file via a background process (not a tool wrapper) timed against the real compile/assemble steps. |
| Two concurrent `build.sh` invocations racing on `agent/lib/` and `target/` — one process's `rm -f` on mismatch could delete a jar another process just verified and is about to consume. Low severity, self-healing on re-run, bundled into #48. | `agent/build.sh` | A harness that launches two real `build.sh` processes against a shared `agent/lib/` with induced timing (e.g. `sleep` shims) and asserts neither corrupts the other's output. |
| The happy-path case (`test_a_correctly_hashed_cached_jar_still_builds`) silently skips on a clean checkout with no local cache, so a `build.sh` that always fails at the checksum step would still pass the whole gate. Filed as #46; the fix needs a design decision (network exception in the test suite, or skip-fails-gate policy) this run deliberately did not make. | `agent/test_build.sh` | Either of #46's two suggested fixes, then a breaker lap specifically targeting whether the gate can still pass with a permanently-broken `build.sh`. |
| Whether a non-GNU `sha256sum` (busybox, macOS `shasum`) produces output `reads_like_an_integrity_failure()` / the unrunnable-verifier message actually match. | `agent/build.sh`, `agent/test_build.sh` | Running the suite on a non-Linux or busybox-based box. |
