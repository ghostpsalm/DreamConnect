- install.sh call site: push_dconf_environment "$USER_NAME" "$USER_UID" immediately

root cause (confirmed by reading install.sh): `loginctl enable-linger` (line 327)
unconditionally starts user@$USER_UID.service BEFORE configure_no_idle_lock (line 354)
writes ~/.config/environment.d/dconf-profile.conf. environment.d is only imported by
systemd --user at manager start, so DCONF_PROFILE never reaches the live manager on
any install — not a race, guaranteed order every run.
